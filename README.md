# 帝国开局助手

面向《帝国时代 IV》玩家的 Windows 中文开局工具，基于 CraftySalamander 的 RTS_Overlay（即时战略悬浮工具）修改，采用 GNU GPL 第三版（通用公共许可证）。

## 安装与更新

首次安装可从 [GitHub 下载安装包](https://github.com/miradore-xyz/aoe4-opening-assistant-zh/releases/latest/download/AoE4OpeningAssistant-Setup.exe)，或使用 [Gitee 国内下载页](https://gitee.com/code_liujiaxin/aoe4-opening-assistant-zh/releases)。

启动后会在后台检查正式发行版。只有发现新版本时，主页顶部才出现下载图标；也可在「设置」底部点击「检查软件更新」。点击图标查看更新内容，下载完成后选择「安装并重启」，无需另外打开发布页。下载文件通过大小和 SHA256（文件内容摘要）校验后才可安装。

GitHub 为主更新源，Gitee 为国内备用更新源，两处提供同一版本的安装包。大陆不同运营商与地区的连接情况尚未全部实测；软件会按已配置来源尝试连接，不能保证所有网络始终直连。

## 中文默认开局

内置来自 AoE4 Guides（帝国时代4开局指南）的23套中文练习提要，每个文明一套，不混入通用演示或更新测试开局。原作者、指南链接与赛季资料保留在各开局文件中，完整列表见 [默认开局来源说明](src/默认开局/来源说明.md)。

原稿明确给出的时间节点自动推进；未写时刻的内容随前一时间组显示为条件提示，完全没有时间的开局仍按条件手动切换。不编造时间或人数。原稿赛季与收藏量不能替代当前补丁下的实战验证。

升级会补齐尚未安装的默认条目；已编辑的内容不覆盖，从库中移除的默认条目不会反复恢复。同一原稿已经手动导入时不重复添加。未经修改的旧出厂演示只迁到个人数据目录的「旧示例备份」，玩家编辑的版本保留。

## 功能

- 导入、编辑和导出开局，按分秒安排村民、建筑、科技与提示。
- 紧凑黑灰界面、统一自绘窗口、彩色底游戏图标；悬浮提示大小可调整。
- 置顶悬浮窗、计时、自动切换与全局快捷键；右上角×可暂停并隐藏悬浮窗，循环检查默认关闭。
- 建筑与科技按文明提供，科技按研究建筑分组。
- 晓晓、云希、晓伊免登录在线朗读与本地语音缓存，也可使用本机系统声音。
- 通过 AoE4 World（帝国时代4战绩站）公开接口搜索玩家、查看最近战绩与按模式统计，搜索记录可删除。
- 设置中的数字框和音量滑杆只通过点击、拖动或键盘修改，滚轮用于滚动页面。

软件不读取游戏内存、不自动操作游戏。公开战绩不包含完整的玩家操作时间线。

## 资料保存

便携版默认使用程序旁的「用户数据」；首次安装默认使用个人应用资料目录。从软件内更新会沿用当前资料目录，保留开局、设置、搜索记录与缓存。卸载程序不删除玩家资料。

本仓库与发行包不包含作者个人资料、查询历史、战绩缓存或语音缓存。内置默认开局属于公开分发资料，独立于玩家个人库。

## 从源码运行

需要 Windows 和 Python（运行环境）3.11。

```powershell
# 建立独立运行环境并安装依赖。
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r src\requirements.txt
# 运行中文助手。
.venv\Scripts\python.exe src\app.py
```

## 构建发行版

`src/release_build.py` 负责生成程序、安装包、校验清单和备用更新清单；安装器采用 Inno Setup（Windows 安装包编译工具）。构建前检查23文明默认资料是否齐全，发行时附带完整对应源码与第三方许可。

更新通道只使用正式发行版；安装包名固定为 `AoE4OpeningAssistant-Setup.exe`，备用更新清单为 `update.json`。各版本使用独立发行标签，已发布的发行附件不覆盖。
